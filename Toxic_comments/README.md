# Toxic_comments

## Классификация комментариев

Магазину нужен инструмент, который будет искать токсичные комментарии и отправлять их на модерацию.

**Задача:** подобрать и обучить модель, которая будет классифицировать комментарии на позитивные и негативные.

**Ход исследования:**
1. Загрузка данных
2. Подготовка данных
3. Обучение моделей
4. Общий вывод

**Вывод:**
- загрузили и изучили данные
- лемматизировали и очистили тексты, применили векторизацию
- обучили модели LogisticRegression, DecisionTreeClassifier
- определили лучшую модель LogisticRegression
